# Quick Step School Limited — Website

Nursery & Primary school website (Meanwood & PHI campuses, Lusaka, Zambia), exported from Google Stitch.

- `index.html` — the site (all 9 tabs), with images served locally from `images/`
- `screen.html` — original Stitch export (hosted image URLs)
- `screenshot.png` — Stitch reference render

Open `index.html` in a browser. Requires an internet connection for Tailwind CDN and Google Fonts.
